# Security

Do not report a vulnerability in a public issue when it includes a credential, private hostname,
private repository detail, or a working exploit against a live StoryLoop deployment.

Until this repository has a dedicated security contact, report sensitive findings privately to the
maintainers through GitHub's private vulnerability reporting for this repository. Ordinary skill
bugs and documentation problems can use public issues.

The skill does not execute code or receive StoryLoop credentials. Treat any contribution that adds
an executable skill script, external network call, secret-handling instruction, or broader
activation rule as a security-sensitive change that needs explicit review.
